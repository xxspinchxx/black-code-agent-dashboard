      how it works
      Loading branches switches the dashboard to live: made-up tasks are cleared, each branch goes to an agent by its name (test/ to the tester, docs/ to the scout, feat/ and fix/ to the builder, release/ and main to the deployer, review/ to the reviewer, plan/ to the planner), and the quest becomes shipping the repo. It re-syncs every 5 minutes. Reads go through your Zapier GitHub connection with your own sign-in; the page never changes the repo. Start a new session from the session menu to go back to the demo.
